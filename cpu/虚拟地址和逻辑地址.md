# 虚拟地址和逻辑地址

`LOADADDR()` 是 GNU 链接器 ld 内置函数，用于获取输出段的 LMA 加载地址；配套区分 VMA 运行地址，核心用于嵌入式启动阶段 Flash 数据搬运到 RAM。

## 1 LOADADDR () 基础定义

### 功能

获取某段​**加载存储器地址 LMA**，即该段在 bin/hex 烧录固件文件内的 Flash 物理存储位置。

### 语法与符号导出示例

链接脚本代码：

ld

```
__l3enc_comm_lma = LOADADDR(.l3enc_comm);
```

1. `.l3enc_comm`：自定义输出段名
2. 返回值：该段对应的 LMA 地址
3. C 代码引用方式

```
extern uint32_t __l3enc_comm_lma;
```

## 2 VMA 与 LMA 核心区分

表格

|缩写|全称|存放介质|核心作用|示例地址|
| ------| --------------------------------------| ----------| ----------------------------------| ----------|
|VMA|Virtual Memory Address<br />虚拟内存地址|RAM|程序运行时 CPU 访问、执行的地址|`0x20000000`|
|LMA|Load Memory Address<br />加载存储地址|Flash|固件烧录文件里数据存放的物理地址|`0x08020000`|

### 一句话区分

LMA \= 下载器烧录数据的 Flash 位置；VMA \= 程序运行时读写数据的 RAM 位置。

## 3 典型应用：上电 Flash → RAM 数据搬移

### 底层原理

带初始化值的全局变量存储在 Flash（LMA），RAM 掉电丢失数据，上电必须将 Flash 原始数据拷贝至 RAM 运行地址（VMA），程序才能正常读写。

### 完整搬运代码

```
extern uint32_t __l3enc_comm_start;  // VMA：RAM运行起始地址
extern uint32_t __l3enc_comm_lma;    // LMA：Flash存储起始地址
extern uint32_t __l3enc_comm_size;    // 段总长度

// 启动初始化执行内存拷贝
memcpy(&__l3enc_comm_start,
       &__l3enc_comm_lma,
       (size_t)&__l3enc_comm_size);
```

## 4 LOADADDR () 与 ADDR () 对比

表格

|ld 内置函数|返回地址类型|使用场景|
| -------------| --------------------------| ---------------------------------------|
|`ADDR(.段名)`|段 VMA（RAM 运行地址）|获取变量运行时访问地址|
|`LOADADDR(.段名)`|段 LMA（Flash 烧录地址）|启动数据搬运，读取 Flash 原始数据地址|

## 核心总结

1. `LOADADDR()` 拿的是段在固件 Flash 中的烧录地址，仅用于上电数据搬移；
2. `ADDR()` 获取段运行时 RAM 虚拟地址，程序正常业务逻辑使用；
3. 带读写属性的初始化数据段，必须依靠 LMA+VMA 完成 Flash 到 RAM 拷贝，否则变量无初始值。
