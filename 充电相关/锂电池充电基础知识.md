# 锂电池充电基础知识

锂电池完整充电流程（工程师总结·可直接笔记）

## 整体四阶段流程（标准锂电）

涓流预充 → 恒流快充(CC) → 恒压充电(CV) → 充满截止

## 1. 涓流预充阶段（Trickle / Pre-charge）

**触发条件**​：电池电压 \< 2.9V\~3.0V（过放/低压状态）

**充电电流**​：0.05C \~ 0.1C（极小电流）

**控制方**：充电IC/PMIC

**为什么必须这个阶段**：

- 电池过放后 SEI 膜损坏、内阻极大、活性差
- 直接大电流会**析锂、发热、鼓包、损坏电芯**
- 小电流缓慢恢复电芯活性、重建SEI膜、安全抬升电压

**阶段结束**​：电压回升到 2.9V\~3.0V，自动切恒流CC

## 2. 恒流快充阶段（CC Constant Current）

**触发条件**：3.0V ≤ 电池电压 ＜ 4.2V

**特征**：电流恒定、电压持续上升

**控制方**：充电IC（唯一主控）

**IC如何恒流（核心原理）** ：

充电电流真正驱动公式：

$$
I = \frac{V_{out}-V_{bat}}{R_{总}}
$$

- 电流不是由单纯 Vout 决定，而是由**压差（Vout − Vbat）** 推动
- IC 通过调节内部 MOS 管的 **Rds(on) 导通电阻** 改变总电阻

**恒流闭环调节逻辑**：

- 实际电流 ＞ 目标电流 → IC 关小MOS导通 → 电阻变大 → 电流下降
- 实际电流 ＜ 目标电流 → IC 开大MOS导通 → 电阻变小 → 电流上升

**阶段结束**：电池电压到达 4.2V（满电截止电压）

## 3. 恒压充电阶段（CV Constant Voltage）

**触发条件**​：电池电压 \= 4.2V

**特征**​：电压锁死不变，电流**自动逐渐下降**

**为什么电流会自动变小？（重点）**

IC 固定输出 4.2V，电池电压不断逼近 4.2V

→ **压差 Vout−Vbat 越来越小**

→ 推动电流的动力不足 → 电流自然下滑

此阶段​**不需要IC限流**，是电池电化学特性自发降流。

## 4. 充满截止阶段

**截止条件**​：CV阶段电流下降至 0.02C\~0.05C

**动作**：IC关闭充电通路，停止充电

**逻辑**：电流已经极小，电池基本饱和，继续充会损伤电芯。

## 关键总结1：谁控制电流？

- **充电端（IC/PMIC）** ：全权控制电流、电压、阶段切换
- **被充电端（电池+BMS）** ​：只采样电压、只做硬件保护，**不参与正常充电调节**

## 关键总结2：两个阶段电流变化本质

- **CC阶段电流恒定**：IC动态调MOS电阻，强行稳住电流
- **CV阶段电流下降**：压差减小，动力变弱，电流自然下降

## 关键总结3：C倍率含义

C \= 电池容量倍率，不是电流单位

1C电流 \= 1小时充满电池的电流

0.05C\~0.1C \= 超小电流，用于低压修复
