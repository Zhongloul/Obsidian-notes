# SBC编码

## 为什么 SBC 每帧采样数 = blocks × subbands？

这个问题问得好，这涉及到 SBC 编码器**时频变换的矩阵结构**。

### SBC 帧的数据组织方式

SBC 编码器对 PCM 音频做**多相滤波器组 (Polyphase Filter Bank)**  变换，将时域信号转换到频域。一帧 SBC 数据内部的音频样点是一个**二维矩阵**：

```
          ←── blocks (时间轴) ──→  
             b0   b1  ...  b15
          ┌────────────────────────┐
  subband 0 │  s0b0  s0b1 ... s0b15 │
  subband 1 │  s1b0  s1b1 ... s1b15 │
     ↓     │    ...  ...  ...  ...  │
  subband 7 │  s7b0  s7b1 ... s7b15 │
          └────────────────────────┘
```

### 两个维度的物理含义

|维度|含义|典型值|
| ------------| -------------------------------------------------------------------------------------------| --------|
|**subbands**（子带数）|将音频频率范围分成多少个频段。8 subbands = 将 0~24kHz(48kHz采样) 分成 8 个频段，每段 3kHz|**4 或 8**|
|**blocks**（块数）|在**时间轴**上，每个子带采集多少个样点。这决定了帧的时间跨度|**4/8/12/16**|

## 为什么 48kHz 采样率的频率范围是 0\~24kHz？

这是 **奈奎斯特-香农采样定理 (Nyquist-Shannon Sampling Theorem)**  决定的。

> 采样率必须  **≥ 2倍** 的信号最高频率，才能无失真地重建原始信号。

```txt
采样率 fs ≥ 2 × f_max
         ↓
可表示的最高频率 f_max = fs / 2
```

### 为什么是乘法关系？

因为 SBC 的一帧编码了 **所有 subband × 所有 block 的交点** 上的音频样点：

```
每帧总采样数 = subbands × blocks
             = 8 × 16
             = 128 个 PCM 采样点（单通道）
```

这就好比一张 **8行×16列** 的表格，每个格子存一个音频样点，总共 128 个格子（样点）。

### 对应的音频时长

```
帧时长 = 总采样数 / 采样率
       = 128 samples / 48000 Hz
       = 0.002666... 秒
       = 2.667 ms ≈ 2.7 ms ✅
```

### 类比理解

可以把 SBC 编码想象成**把音频切成小块再压缩**：

```
┌──────────────────────────────────────────┐
│            原始 PCM 音频流                  │
│  sample: 1  2  3  4  5 ... 128  129 ...  │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│  │ SBC帧 #1  │ │ SBC帧 #2  │ │ SBC帧 #3  │  │
│  │ 128个样点 │ │ 128个样点 │ │ 128个样点 │  │
│  │ 2.667ms  │ │ 2.667ms  │ │ 2.667ms  │  │
│  └──────────┘ └──────────┘ └──────────┘  │
└──────────────────────────────────────────┘
```

### 总结

**每帧采样数 = blocks × subbands** 的原因：

1. SBC 使用**子带编码**，将音频分成多个频段（subbands）
2. 在每个频段上采集多个时间样点（blocks）
3. 一帧包含了**全部频段 × 全部时间样点**的完整矩阵
4. 因此总样点数 = 频段数 × 时间样点数 = **subbands × blocks = 8 × 16 = 128**
5. 128 samples / 48000 Hz = **2.667ms ≈ 2.7ms** ✅
