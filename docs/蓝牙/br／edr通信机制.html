BR／EDR通信机制

经典蓝牙 BR/EDR 基带时序与链路技术笔记

一、底层时序基础：625μs 时隙 + 奇偶 TDD 分时双工

  1. 最小调度单元
    1 Slot = 625μs；2 个时隙（偶数 + 奇数）组成 1 帧，时长 1.25ms。
  2. 基础收发权限铁律（单时隙小包）
  • 偶数时隙（0/2/4…）：主机 Master 拥有发送权，从机 Slave 仅能接收；
  • 奇数时隙（1/3/5…）：从机 Slave 拥有发送权，主机仅能接收。
  1. 多时隙 ACL 长包扩展（DH1/DH3/DH5）
    ACL 异步数据支持连续占用 1/3/5 个时隙提升吞吐；发包所有权只看起始时隙奇偶：
  • 主机从偶数时隙发起长包：整条连续时隙全部归主机发送，区间内奇数时隙从机禁止上行；
  • 从机从奇数时隙发起长包：整条时隙归属从机，区间偶数时隙主机无法下发；
    长包仅临时封锁对端发送通路，底层时隙时钟基准不变。

二、全网同步体系：无固定锚点，依靠主机统一时钟对齐

BLE 依靠连接事件 Anchor 完成同步，经典蓝牙无全局锚点，依靠三级时钟实现时序同步：

  1. CLKN（本机原生时钟）
    每台设备独立 28bit 自由运行计数器，永不清零，是本机扫描、跳频、时隙调度的唯一基准。
  2. CLKE（预估时钟，仅寻呼 Page 阶段）
    主机通过 Inquiry 查询获取从机 CLKN 快照，计算偏移生成 CLKE，用于预测从机 Page Scan 开窗时刻，加快寻呼连接速度。
  3. 微微网基准 CLK
    等同于主机自身 CLKN；从机收到 FHS 同步包后计算 slave_offset，使用「本地 CLKN + 偏移」对齐全网时隙时序。
  4. 接收容错窗口
    稳定连接态接收窗口 ±10μs（总 20μs），抵消晶振温漂、频偏；长时间无数据包会自动加宽窗口；每次成功接收数据包都会实时修正时钟偏移。

三、完整建链流程：设备发现 → 定向寻呼 → 正式连接

（一）Inquiry 查询（发现周边未知设备）

使用通用查询接入码 GIAC，遍历 16 条查询信道；仅获取周边设备 BD 地址、设备类型、粗略时钟，不建立物理链路。

（二）Page / Page Scan 寻呼（定向建链、完成时钟同步）

  1. Page（主机侧）：已知目标 BD 地址，生成专属 DAC 接入码，持续发送 ID 呼叫包；收到从机应答后下发 FHS 核心同步包，携带主机完整 CLKN、微微网 CAC、跳频参数，完成全网时序基准同步。
  2. Page Scan（从机侧）：待机状态周期性唤醒宽窗口射频，监听寻呼信号，适配 CLKE 预估带来的时序误差。

交换 FHS 包后主从时钟完成对齐，进入 Connection 正式连接态。

（三）Connection 三种工作功耗模式

  1. Active 活跃模式（非休眠）
    硬件强制每个时隙打开射频接收窗口，持续监听维持时钟同步；发送窗口按需开启，无业务数据可静默不发包，允许连续多时隙空窗；上层可周期性发送 POLL/NULL 保活包，防止链路超时断开；射频持续上电，整机功耗偏高。
  2. Sniff 嗅探低功耗模式（耳机、穿戴设备主流）
    主从通过 HCI 协商 Sniff Interval 嗅探周期，仅约定窗口内唤醒射频收发；窗口外全部时隙射频完全关闭，抓包波形可见大片无数据包空白区间，大幅降低平均功耗。
  3. Hold/Park 深度休眠：休眠间隔更长，音频类设备极少使用。

四、两类核心业务链路：SCO/eSCO 同步语音 + ACL 异步数据

（一）SCO/eSCO 通话同步语音链路（硬实时，静态抢占时隙）

  1. 底层仍遵守奇偶 TDD 规则，固定成对时隙传输：偶数时隙主机下发语音、相邻奇数时隙从机回传上行语音；
  2. 建通话链路时协商固定周期 Tsco（可选 2/4/6/8/12 时隙，例 12 时隙对应 7.5ms 一轮语音交互）；
  3. 基带硬件强制周期发包，不允许静默；该组时隙永久预留给语音，ACL 数据仅能使用剩余空闲时隙；
  4. SCO 无重传机制，丢包直接丢弃；eSCO 内置周期重传窗口，降低通话杂音；仅支持单时隙小包，不支持 DH3/DH5 多时隙大包。

（二）ACL 异步数据链路（承载 A2DP 音乐、SPP 串口、HID 键鼠）

  1. 时隙动态共享，无硬件预留时隙；支持 DH1/DH3/DH5 多时隙大包，最大化传输吞吐量；
  2. 无硬件强制发包要求，无数据时可长时间静默；采用异步重传机制，延迟不可控，依靠本地音频缓存抵消时序抖动；
  3. 若已建立 SCO 语音，ACL 仅能使用未被语音锁定的空闲时隙传输数据。

五、抗干扰机制：自适应跳频

微微网跳频序列由「主机 CLK + 微微网 CAC 地址」唯一计算生成；主从时钟对齐后，每时隙同步切换对应信道，规避 2.4GHz 频段 WiFi、其他蓝牙设备同频干扰。

六、关键约束与区分要点

  1. 收发硬约束：空闲偶数时隙仅主机可发包；仅从机发起奇数起始的多时隙长包时，才会占用区间内偶数时隙上行传输。
  2. 三类空白时隙本质完全不同：
    ① Active 静默：射频持续接收，仅关闭发射通路，不属于休眠；
    ② Sniff 空白：射频全程关闭，设备主动低功耗休眠；
    ③ SCO 空闲时隙：射频持续接收，时隙预留给 ACL，仅不传输语音。
  3. 音频短板：A2DP 基于异步 ACL 链路，无硬件等时时序保障，延迟、抖动、丢包表现弱于 LE Audio BIS 广播音频方案。

七、极简总览

经典蓝牙以 625μs 时隙 + 奇偶 TDD 分时收发作为底层调度核心，依靠主机 28bit 自由时钟实现无锚点全网同步；通过查询、寻呼两步完成设备发现与时序对齐；连接态分为 Active 活跃、Sniff 低功耗两种主流工作模式；SCO/eSCO 静态抢占固定时隙承载低延迟通话，ACL 动态共享剩余时隙传输音乐与数据，搭配自适应跳频完成 2.4G 环境抗干扰通信。
